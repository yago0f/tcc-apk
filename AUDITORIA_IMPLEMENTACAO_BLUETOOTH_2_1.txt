LIMITAÇÃO DO AMBIENTE DE GERAÇÃO
O npm install não pôde ser concluído aqui porque o ambiente de execução não conseguiu acessar o registro npm dentro do tempo disponível. Portanto, a compilação nativa Android e o teste físico com um HC-05 real precisam ser executados no seu computador/celular após npm install. Isso não foi mascarado como teste concluído.

TESTE FINAL RECOMENDADO NO SEU PC
1. npm install
2. npm run verify
3. npx expo-doctor
4. npx expo prebuild --platform android --clean
5. npx expo run:android --device
6. Parear HC-05 no Android.
7. Abrir o app -> Conexão -> permitir Dispositivos próximos.
8. Confirmar que HC-05 aparece destacado.
9. Conectar manualmente.
10. Tocar ABRIR: servo deve ir para 0°.
11. Tocar FECHAR: servo deve ir para 180°.
12. Fechar/abrir o app e confirmar que HC-05 continua marcado como preferido sem conectar sozinho.
